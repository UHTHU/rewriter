This editor matches a bundled list of English phrases and proposes shorter alternatives. It uses no language models, remote APIs, analytics, cookies, or browser storage.

Your draft lives in this tab’s memory. Reloading clears it. Import reads files on your device; export creates a file on your device. The local server only serves application files.

Where do the rules come from?

Original Rewriter rules are combined with all 327 entries from the pinned MIT-licensed retext-simplify dataset by Titus Wormer. After merging overlaps, there are 394 distinct phrase rules. Analysis checks adapt write-good (MIT) — weasel words, passive voice, repeated words, weak wording, wordy phrases — and proselint (BSD-3-Clause) — redundancy, hedging, uncomparables. Readability scores follow textstat’s published formulas (MIT). Suggestions with a safe rewrite are offered for review; purely diagnostic checks appear as findings and never edit your text. Imported suggestions show their source and require explicit acceptance. Where available, choose among replacements or removal. Overlapping original rules retain their existing context checks. Style suggestions also require acceptance. No upstream services or dependencies are used.

What is protected?

The editor skips recognized code blocks, inline code, links, math, common citation forms, LaTeX commands, and optionally quoted text. You can also protect specific terms. These are pattern-based protections, not complete document parsers. Review specialist documents carefully.

What is measured?

Word counts, approximate words per sentence, and approximate readability (Flesch Reading Ease, Flesch–Kincaid, Gunning Fog, SMOG, Coleman–Liau, ARI) using textstat’s formulas with a heuristic syllable counter. There is no AI-authorship score or guarantee about detector outcomes. Suggestions can alter nuance; accept only the ones that fit.
